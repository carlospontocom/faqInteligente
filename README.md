# FAQ Inteligente 🚀

Uma aplicação web moderna e interativa desenvolvida com **Vue 3** e **Quasar Framework**, integrada ao **EmailJS** para envio direto de mensagens via formulário de contato e implantada na **Vercel**.

## ✨ Funcionalidades

* 💡 **FAQ Dinâmico:** Interface intuitiva e rápida para consulta de dúvidas frequentes.
* 🔐 **Autenticação / Login:** Tela dedicada para controle de acesso do usuário.
* 📩 **Formulário de Contato Direto:** Envio de e-mails integrado via API REST do EmailJS (Axios).
* 🛡️ **Segurança Configurada (CSP):** Políticas de Segurança de Conteúdo (Content Security Policy) aplicadas para produção na Vercel e ambiente local.
* 📱 **Design Responsivo:** Layout adaptável para telas móbile, tablet e desktop alimentado pelos componentes do Quasar.

---

## 🛠️ Tecnologias Utilizadas

* **Framework Frontend:** [Vue.js 3](https://vuejs.org/)
* **UI Component Library:** [Quasar Framework (v2)](https://quasar.dev/)
* **Cliente HTTP:** [Axios](https://axios-http.com/)
* **Serviço de E-mail:** [EmailJS](https://www.emailjs.com/)
* **Hospedagem & Deploy:** [Vercel](https://vercel.com/)
* **Bundler & Tooling:** Vite / Webpack (via Quasar CLI)
